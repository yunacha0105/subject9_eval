**3. 계산**

```text

```

**4. 캐시 비교표**

| 경로 | 캐시 | HTTP 응답(ms) | 추론시간(ms) | 메모 |
|---|---|---:|---:|---|
| 동기 | MISS | 22.499 | 17.50 | 모델 실제 추론, 5회 중앙값 |
| 동기 | HIT | 미측정 | NULL | 캐시 재사용 시 모델 추론 생략 |
| 비동기 | MISS | 7.429(접수) | 19.11 | 5회 중앙값, 최종 확인 62.997ms |
| 비동기 | HIT | 15(접수) | NULL | 웹 화면 단일 측정, 최종 확인 1,032ms |

**5. 해석**

- 비동기 접수 HTTP 응답은 동기 결과 응답보다 66.98% 빠르게 반환됐다.
- 위 수치는 **모델 추론이 빨라졌다는 뜻이 아니며**, 작업 접수와 실제 처리를 분리한 효과다.
- 최종 확인시간은 동기 방식보다 40.498ms 길게 측정되었다. 비동기 방식은 큐 대기 및 상태 조회 과정이 추가되기 때문이다.
- Cache HIT의 `inference_ms=null`은 모델 추론을 생략했다는 뜻이다.
- 비동기 Cache HIT는 실제 동작을 확인하였으나, MISS와 HIT의 측정 방식 및 반복 횟수가 달라 직접적인 성능 비교에는 사용하지 않았다.
